# הקופה

אפליקציית PWA לניהול צדקה. עברית מלאה, RTL, מותאמת למובייל.

**כתובת האפליקציה** — `android.url` שבתצורה.

## הפעלה ראשונה

1. הריצו מול פרויקט ה-Supabase (`supabase.url` שבתצורה), דרך ה-SQL Editor,
   את `gius/migrations/000_schema.sql` ואז את `migrations/000_schema.sql` —
   הבעלים ראשון, והרצה חוזרת אינה משנה דבר.
2. הזינו את הפלעדזש לשנה ב-SQL Editor — ⛔ אין מסך שיוצר אותו; ⭐ החודשים
   נגזרים מתאריך הרשומה, ⚠️ ואינם מוזנים.

## מסכים

- **החודש** — הכנסות, כרטיס החומש, כרטיס הפלעדזש, ופירוט הרישומים.
- **רישום** — מסך אחר מסך, שדה אחד בכל פעם, ואישור בהחלקת מטבע.
- **הגדרות** — הוראות קבע, רשימת המקורות, סדרת החודשים מול היעד, ומתג
  המשוב החושי.

## פיתוח

הכל בקובץ אחד: `index.html`. אין build.

```bash
node tools/guard.mjs       # שומר הדחיפה — חובה לפני כל push
node tools/gen-app.mjs     # מחדש מהתצורה את קובצי הפלטפורמה והאייקונים
```
